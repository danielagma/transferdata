### 🔴 BUG: 400 Bad Request / Deserialization Error when saving Bond Reference Data as 32nd

**Environment:** DEV2
**Component:** Backend (Ref Data CAPI)

**Description:**
When attempting to save a bond configuration with the "32nd" Pricing Format, the CAPI backend rejects the execution returning a 400 Bad Request due to a schema validation/conversion error.

**Root Cause (From DevTools Network Analysis):**
1. **PricingFormat Enum Mismatch:** The CAPI backend fails to convert the incoming string value `"ThirtySecond"` into the internal type `Santander.Darwin.Bonds.ReferenceData.Contracts.Bonds.PricingFormat`.
2. **Missing Property:** The backend validation demands a `"contract"` parameter which is causing a secondary validation failure.

**Payload sent by FE:**
`"pricingFormat": "ThirtySecond"`

**API Error Response:**
"Error converting value \"ThirtySecond\" to type 'Santander.Darwin.Bonds.ReferenceData.Contracts.Bonds.PricingFormat'. Path 'pricingFormat', line 1, position 86."
