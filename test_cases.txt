Feature: Ladder View - Vertical Quantity Bar with Fixed Values (DWU-180)

  As a trader
  I want the quantity selection bar in the D2D Market Depth "escalator" widget to be displayed vertically with predefined fixed quantities
  So that I can quickly select commonly used sizes during fast market conditions

  Background:
    Given the user has logged into Darwin
    And the user navigates to the "Order Management" screen
    And the user opens the Escalator View for a selected instrument

  # Covers AC1 and AC2
  Scenario: Vertical quantity bar layout and predefined fixed values
    When the system renders the Escalator widget
    Then a vertical quantity selection bar is displayed adjacent to the price ladder
    And the bar contains the fixed configurable values: 10, 25, 50, 75, and 100

  # Covers AC3 and AC4
  Scenario: Quantity selection and visual highlighting
    Given the vertical quantity bar is visible on the Escalator widget
    When the user clicks on a specific quantity value (e.g., "25")
    Then the selected quantity button is clearly highlighted with a visual distinction
    And the selection is immediately reflected as the active order size for the widget

  # Covers AC5
  Scenario: Configuration supports future updates to quantity values
    Given the system administrator updates the configuration to set new quantity values
    When the user accesses the Escalator widget
    Then the vertical quantity bar dynamically displays the newly configured values
